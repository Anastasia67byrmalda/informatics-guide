\# Информатика для первокурсника: Системы счисления



\*\*Автор:\*\* Anastasia  

\*\*Выбранная тема:\*\* Системы счисления  



\## Цель справочника

Краткое учебное пособие для студентов первого курса, помогающее разобраться в принципах записи чисел в различных позиционных системах счисления и правилах перевода между ними.



\## Состав проекта

\- `README.md` — общее описание справочника и инструкция по работе с ним.

\- `glossary.md` — словарь основных терминов по теме.

\- `examples.md` — пошаговые разобранные примеры перевода чисел.

\- `sources.md` — список использованной литературы и интернет-ресурсов.

\- `questions.md` — вопросы для самопроверки знаний.
