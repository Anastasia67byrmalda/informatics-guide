\# Информатика для первокурсника: Системы счисления



\*\*Автор:\*\* Anastasia  

\*\*Выбранная тема:\*\* Системы счисления  



\## Цель справочника

Краткое учебное пособие для студентов первого курса, помогающее разобраться в принципах записи чисел в различных позиционных системах счисления и правилах перевода между ними.



\## Состав проекта

\- `README.md` — общее описание справочника и инструкция по работе с ним.

\- `glossary.md` — словарь основных терминов по теме.

\- `examples.md` — пошаговые разобранные примеры перевода чисел.

\- `sources.md` — список использованной литературы и интернет-ресурсов.

\- `questions.md` — вопросы для самопроверки знаний.

\## Как пользоваться справочником

1\. Начните изучение темы с файла `glossary.md`, чтобы познакомиться с базовыми терминами и определениями.

2\. Перейдите в `examples.md` и последовательно разберите пошаговые алгоритмы перевода чисел между системами счисления.

3\. Проверьте свои знания с помощью вопросов для самоконтроля в файле `questions.md` (сначала попробуйте ответить самостоятельно, затем сверьтесь с готовыми ответами).

4\. Для углублённого изучения материала обратитесь к проверенным учебным материалам из списка в `sources.md`.
