\# Глоссарий: Системы счисления



1\. \*\*Система счисления\*\* — знаковая система, в которой числа записываются по определённым правилам с помощью символов некоторого алфавита.

2\. \*\*Алфавит системы счисления\*\* — совокупность всех уникальных цифр и символов, используемых для записи чисел в данной системе.

3\. \*\*Основание системы счисления\*\* — количество различных цифр, используемых для изображения чисел в позиционной системе счисления.

4\. \*\*Позиционная система счисления\*\* — система, в которой количественное значение каждой цифры зависит от её места (позиции) в записи числа.

5\. \*\*Непозиционная система счисления\*\* — система, в которой значение цифры не зависит от её положения в числе (например, римская система).

6\. \*\*Разряд\*\* — рабочее место цифры в записи числа; номер разряда отсчитывается справа налево начиная с нуля для целой части.

7\. \*\*Двоичная система счисления\*\* — позиционная система с основанием 2, использующая только две цифры (0 и 1) и лежащая в основе работы компьютеров.

8\. \*\*Шестнадцатеричная система счисления\*\* — позиционная система с основанием 16, использующая цифры 0–9 и латинские буквы A–F для компактной записи двоичных данных.
